# TripVista - Bus Booking Management System

TripVista is a simple and user-friendly online bus booking website.
Users can search buses, select seats, enter passenger details, make payments,
and manage their bookings.

## Features

- User Registration & Login
- Search Bus
- Select From City and To City
- Select Journey Date
- View Available Buses
- Bus Facilities:
  - AC
  - Water
  - Charging
- Select Bus
- Select Seat
- Enter Passenger Information
- Online Payment
- Booking Confirmation Card
- My Bookings
- View e-Ticket
- Print Ticket
- Download e-Ticket
- Cancel Ticket
- Completed Tickets
- Blue & White Modern UI
